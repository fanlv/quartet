# Quartet iOS

Quartet 的原生 SwiftUI 客户端，面向个人内部分发和局域网使用。客户端只连接用户自己运行的 Quartet 后端，不在 iPhone 或 iPad 本地运行 Agent，也不直接访问后端机器文件系统。

## 当前代码状态

当前仓库中的 iOS 工程已实现首个纵切代码，能力范围包括：

- 单个可配置后端，默认 `https://devbox.fanlv.fun/`
- 健康检查与按需 Token 验证
- Keychain Token 存储，服务地址保存在 `UserDefaults`
- 工作空间列表、筛选和服务端共享的默认 Agent/模型读写
- Job 分页列表、详情、停止、置顶、重命名和删除
- 新建 Agent 对话，支持选择工作空间、Agent、模型、模式和思考等级
- 新建和继续对话均支持照片库、相机、系统图片文件，并在必要时压缩后上传
- 会话历史、普通 Job SSE、Markdown、安全链接、可单独复制的代码块、思考内容、工具调用、历史图片和完整错误展示
- 普通 Job 运行中的页面内存队列、取消待发送、发送失败恢复草稿或重试
- Graph run 状态轮询、运行概览、节点详情、节点会话/Shell 输出，以及停止、步骤后停止、取消停止、恢复和讨论完成动作
- 应用内通知中心、完成/失败/等待人工/连接异常偏好、本地通知、持久化和按运行事件去重
- 工作空间和 Job 摘要缓存、过期/待同步提示；进入后台停止 SSE，回到前台后重新读取快照并恢复事件流
- 当前导航使用“运行台”“设置”两栏；通知中心从运行台或设置页以 sheet 打开

## 环境

- macOS
- Xcode 26 或更新版本
- iOS 26.0 或更新版本
- 可访问 Quartet 后端的局域网

项目没有第三方依赖，也不需要 CocoaPods 或 Swift Package 下载。

## 运行

1. 在 macOS 上打开 `Quartet.xcodeproj`。
2. 在 Quartet target 的 Signing & Capabilities 中选择个人开发团队。
3. 连接 iPhone，选择设备并运行。
4. 首次启动时确认服务地址并填写 `X-AGENT-AUTH` Token；未启用鉴权可留空。

## 验证边界

当前会话在 Linux 环境中只能做文件级静态检查，不能运行 Xcode 构建、Swift 编译、iOS Simulator 或真机测试。任何发布、可安装包、Keychain 行为、照片权限、SSE 后台恢复和局域网连接结果，都必须在 macOS + Xcode + iPhone 或 Simulator 上重新验证后才能标记完成。
