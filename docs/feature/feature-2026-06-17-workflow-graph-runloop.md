# 技术方案：工作流图执行引擎（runloop 升级）

## 背景

当前「Loop 任务」引擎（`services/job`）是一棵 `FlowNode` 树（step 叶子 / group 容器），**深度优先严格串行**：结点排成一条线，无并行 / 分支 / 跳转；以路径 `[]int` 为主键管理 resume 与 progress；全局单一「当前会话」靠 `roundMode`（beforeRound / eachRepeat / none）决定新建 / 复用 / 重置；变量是全局 map、`{{变量}}` 单次替换且只有 Shell 能写回；循环靠 group 的 iterationCount，评估结点输出 STOP 提前跳出所在 group。

**痛点**：树形串行模型无法表达「一个结点多个后继 / 多个前驱」，撑不起并行与分支。用户希望编排复杂工作流（如「并行评审+测试 → 评估 → 通过则部署否则修复」），现有引擎无法落地。

## 目标

新增一套**图（nodes + edges）工作流执行引擎**（独立 `graph` 模块），与现有 Loop 引擎并存，支持：

- 五种业务结点：Shell / Prompt / 评估 / If-Else / 循环；外加 start / end 控制结点表达入口与终点。
- **并行**：一个结点连出多条边，下游分支真并发跑 Agent。
- **汇总**：多入边等全部入边解析后，至少一条激活则执行、全部剪枝则自身剪枝并向下游传播。
- **条件分支**：If-Else 按条件只走 yes 或 no 一条路。
- **循环**：循环结点为容器，内部子图按「固定次数 / 直到条件」重复。
- **变量传递**：Shell / Prompt / 评估可声明输出变量，下游 `{{变量}}` 引用；If-Else 只路由不产出，start / end 不产出，循环产出为轮末快照。

> **独立性约定**：现有 Loop 前后端（`services/job` 树形引擎、`LoopConfigPanel`）全部保留、不删不改，存量任务走旧逻辑。新能力落在独立 `graph` 模块与独立画布入口，两套引擎 / 数据模型 / 前端入口物理隔离，无共享可变状态、无分流、无灰度。

## 范围

**做**：图数据模型 + 就绪队列调度引擎；按现有分层做图配置 / 运行记录 / 实例状态 / 变量快照 / 会话血缘持久化；真并发执行（并发度可配）、拓扑并行汇总、剪枝传播的条件分支、子图重复的循环；结点级与 job 级执行超时兜底；可执行结点产出变量；React Flow 画布作独立入口并适配手机端；一次性单向迁移把存量 Loop 配置**转换**为等价图配置（供新画布编辑重跑，不回写原配置）。

**不做**：特殊汇聚策略（race / vote / N 选 K，只支持「等全部入边解析」）；循环内变量按轮隔离（确认不隔离，见 §3）；输出变量的多行 / 结构化值（只支持单行标量）。

## 方案设计

### 1. 数据模型

**工作流图** = 结点列表（稳定 ID、类型、标题、类型专属配置、可选输出变量「名+类型」、可选父容器 ID）+ 连线列表（起点、终点、可选出端口 yes/no）+ 初始变量表（沿用 variables / disabledVars）。

**变量类型**：输出变量在结点配置上显式声明类型，写入时按声明类型解析产出（解析不出即结点失败并全量报错）；下游引用与条件比较一律以声明类型为准，根除 `"10" > "9"` 歧义：

- `string`：原样，字符串比较。
- `number`：十进制（含正负与小数），数值比较。
- `bool`：true/false，仅允许 `==`/`!=` 与真值判断，做 `>`/`>=`/`<`/`<=` 视为类型不一致并报错。

**输出变量契约**（Shell / Prompt / 评估共用）：

- 未声明则不解析输出；声明后须为每个变量给出一行 `QUARTET_OUTPUT:<变量名>=<值>`，同名多行取最后一行。
- **行首锚定**：解析前 trim 行首空白，仅匹配「行首紧跟 `QUARTET_OUTPUT:`」的行，前缀前有非空白字符不视为 marker（避免解释性文本 / 代码块误命中）。
- 变量名须匹配 `[A-Za-z_][A-Za-z0-9_]*`；按每行首个 `=` 切分；变量名 trim，值原样保留（可空、可含 `=`、不 trim）；只支持单行标量。
- 未声明变量行、缺声明变量行、类型解析失败、变量名非法、声明变量值跨行等均判结点失败并全量报错。Shell 从 stdout 解析（错误含 stdout / stderr / exit code）；Prompt / 评估从模型原始输出解析（错误含原始输出），并在用户 prompt 后追加固定协议后缀引导逐行输出。

**结点语义**：

- **Shell / Prompt**：复用现有单结点执行能力，输出变量可选；可选配结点级超时（缺省取运行配置全局默认，见 §2）。
- **评估**：跑 Agent 做判断的专用结点——强制至少一个输出变量、禁止分支出边、UI 以判断/决策呈现、prompt 追加判断导向后缀；产出带类型具名变量供 If-Else / 循环「直到条件」消费（停止语义改由后续条件结点决定，不再用旧 `LOOP_DECISION:STOP` 单布尔 marker）。
- **If-Else**：配一个条件表达式，真激活 yes、假激活 no，另一条剪枝；只路由不产出。
- **循环**：容器，内部子图按父容器 ID 关联，按固定次数 / 直到条件重复，每轮是子图结点的全新实例。
- **start / end**：控制结点，表达入口与终点（均可多个），不执行动作、不产出、不计入业务 progress 分母；start 不允许入边须有出边，end 不允许出边须有入边。

**条件表达式**（If-Else 与循环「直到条件」共用）：对当前结点可见变量求值的布尔表达式，不直接调用 Agent（需 Agent 判断时由上游评估结点先产变量）。保存时静态语法校验、运行时校验变量存在性与类型一致性，错误全量返回。

- **文法**：表达式 = `且`/`或`/`非` 与括号 `()` 组合的布尔项；布尔项 = 比较式 / 真值判断（`{{变量}}` 或 bool 字面量）/ 括号子表达式。
- **优先级**（高→低）：`()` > `非` > 比较 > `且` > `或`，同级左结合；改变结合顺序用括号，保存时校验括号配对。
- **字面量**：字符串用英文双引号 `"..."`；number 为十进制（含正负小数，如 `-3.14`）；bool 为 `true`/`false`。比较两侧类型须一致，否则运行时按类型错误失败；bool 仅 `==`/`!=` 与真值判断。

**变量引用语义**（文本替换与条件求值通用）：

- 文本替换（Prompt / Shell 配置）：未知变量、被剪枝未产出变量保留原始 `{{变量}}` 字面量不报错；被禁用变量替换为空串。
- 条件求值：未知变量、被剪枝未产出变量按未知处理并运行时失败；被禁用变量按空串，空串只在真值判断中为 false，不能参与数值 / 布尔比较。
- 输出变量解析只解析结点自身最终输出，不对解析出的值二次替换。

**图合法性规则**（保存时校验，全量提示违规项）：

- 至少一个 start；至少一个从 start 可达的 end，无 end 不允许保存。
- 控制结点不允许配业务动作 / 输出变量 / yes-no 端口；start 无入边须有出边，end 无出边须有入边。
- 普通可执行结点须有入边（仅 start 与循环子图入口可无入边）与出边；所有路径须最终到达 end，无隐式终点；start 以外不可达结点不允许保存。
- 非循环不允许成环，环只能由循环容器表达。
- If-Else 必须配 yes/no 两出端口，普通结点不允许用 yes/no 端口。
- **循环子图边界**：边不得跨容器（容器外只连循环结点本身，内部子结点只能互连或连容器内 end）；每个子图恰好一个入口（容器内无入边的结点，零或多个均非法）、至少一个内部 end、所有内部路径须到达内部 end；嵌套循环按父容器 ID 分层、规则一致。
- **并行 / 汇总无专用结点**：并行 = 多出边，汇总 = 等全部入边解析后按上述语义判定，跨分支信息靠变量传递。

### 2. 执行引擎：就绪队列调度器

从零实现，不复用 Loop 递归树 walk：

- **调度**：每结点维护「未满足入边计数」，入口先就绪；结点完成后把出边标记激活 / 剪枝，下游计数减一、归零入就绪队列。start 直接激活出边；end 入边解析完只记录路径终止，不激活后继。
- **并发**：就绪结点并发执行，并发度存运行配置（默认 4、最大 16，为 1 退化串行，非法值保存报错）。并发度是**整个 run 的全局上界（单一信号量）**，主图与所有（含嵌套）循环子图结点共享同一额度，不为每个子图另开，故「主图并行 + 循环内并行同时在飞」时资源 / 额度消耗可预期。
- **分支与剪枝传播**（防 join 死锁，n8n / Argo / Temporal 标准做法）：边三态 = 待定 / 已激活 / 已剪枝；分支结点只激活一条出边、另一条剪枝；结点所有入边解析后，至少一条激活则执行、全部剪枝则自身剪枝并向下游传播。
- **执行超时兜底**（防结点 hang 死）：
  - 结点级：可执行结点（Shell / Prompt / 评估）可选超时，运行配置带全局默认、结点可覆盖；超时取消该结点上下文、按失败处理并触发失败传播，全量说明超时与时长。
  - job 级：运行配置可选 job 总超时，超时按 job 失败、取消全部在飞结点，全量说明。
  - 取消遵循「在飞 Agent 取消」规则（§4：ACP 只发 cancel 不 reset session）；超时不触发瞬态重试。
- **终止语义**：队列空即自然结束（到达某 end 只终止该路径，其余结点跑到队列空，部分 end 被剪枝属正常）。无失败 → 成功；任一失败 → 整个 job 失败并取消其它在飞结点（失败传播）。**特例**：结束时若无任何 end 被激活（所有 end 路径被剪枝），判 job 失败并全量说明「无终点到达」（合法性校验只保证存在可达 end，不保证运行时必有 end 激活）。主动终止信号有二：外部「停止」与执行超时。
- **瞬态错误重试**：沿用 Loop 策略——网络重置 / HTTP2 流错误重试 2 次（固定退避），限流 / 额度错误重试 3 次（指数退避）；重试在结点内部完成，不改变入/出边状态与 progress 终态。

**循环子图驱动**：

- 循环结点就绪时启动子图，子图结束后激活出边继续主图。
- 固定次数 ≥ 0，为 0 跳过子图直接激活出边；「直到条件」先跑一轮再轮末求值（**do-while，至少一轮**；需「不满足则一轮都不跑」由用户在循环前用 If-Else 旁路整个循环）。
- 「最大次数兜底」始终生效防死循环（默认 100、最大 1000，非法值保存报错；固定次数模式取「固定次数与上限的较小值」）；达上限即使未满足也结束并全量说明。
- 每轮从唯一内部入口启动，所有内部路径到达内部 end 或被剪枝后才判「直到条件」或进入下一轮；全部内部路径被剪枝时本轮仍正常结束。
- 循环内任一结点失败触发失败传播；被剪枝结点按跳过计入 progress。

### 3. 三块基础设施

借鉴 Loop 思路，新模块独立实现。

**① 实例标识** — 用「结点 ID + 循环迭代上下文」作执行实例稳定键（不再用 `[]int` 路径），Progress / Resume / 回填均以实例键索引，天然支持并行与多前驱、覆盖嵌套循环。

**② 会话血缘（沿边传递）** — Agent 类结点在配置上声明会话策略：新建，或继承上游（仅允许唯一入边）。并行分叉时每条分支复制上游上下文后**新建独立会话**（不复用 session ID 避免污染）；多入边 Agent 结点视为 join、必须新建，配置为继承则保存报错；约束「每条 start 链路首个可执行 Agent 结点必须新建会话」。运行时不依赖 roundMode。

「复制上游上下文」指复制对话历史、模型配置、工作目录、系统提示词、可恢复所需 agent 元数据与工具可见上下文，据此创建新后端 session；不复制运行中 turn 状态、不复用 ACP/eino 原 session ID、不复制进程内临时句柄。ACP 后端若不支持直接 fork，则用持久化历史消息 replay 出等价新 session，replay 失败作结点启动失败全量返回。

**roundMode → 会话策略映射（仅迁移期使用）**：

| 旧 roundMode | 语义 | 转换后会话策略 |
| --- | --- | --- |
| `beforeRound` | 整轮共用一个会话 | 链路首个 Agent 结点「新建」，其余「继承上游」（沿迁移生成的边） |
| `eachRepeat` | 每轮重置会话 | 循环子图入口 Agent「新建」，子图内其余「继承上游」；每轮新实例即新建独立会话，天然等价 |
| `none` | 每结点独立会话 | 全部 Agent 结点「新建」 |

迁移产物若出现「多入边 Agent 被映射为继承」（违反 join 必须新建约束），转换失败并全量报错，不写半成品。

**③ 变量产出与可见性**：

- **可见性**：运行时唯一读语义来源是「每个执行实例的可见变量快照」，无并行可写全局 map。start 快照来自初始变量表；单入边结点继承上游完成后快照；多入边 join 在全部入边解析后合并已激活上游快照（被剪枝入边不参与）。变量只沿连线向下游可见，**无边约束的并行结点间不保证互相可见**，需传递的信息应经显式连线汇聚后再读。
- **join 合并**：不同上游写不同变量取并集；同名变量在同一可并行区域保存时已禁止，因循环不同轮次覆盖则取最新轮次。
- **替换时机**：结点开始执行那刻对其快照做文本替换（规则见 §1）。
- **并发写安全**：产出由调度器在完成回调里**串行落库（单写者）**；物理落库顺序不影响快照。
- **写冲突规则**：两结点无祖先/后代关系且可能同次运行都被激活，视为同一可并行区域，区域内不允许多结点声明同名输出变量（保存时静态校验、全量提示冲突结点）；循环同一结点跨轮写同名变量允许覆盖（取最新轮次值）。
- **被剪枝分支输出变量**永不写入（引用规则见 §1）；需默认值由用户在更上游显式初始化。
- **循环内变量按快照沿轮次累积、不做轮间隔离**：每轮唯一内部入口实例继承「上一轮累积快照」（首轮继承循环入口快照），轮末写回累积快照供下一轮与「直到条件」读取；如需轮间清理由用户在循环末尾结点显式置空。
- **循环轮末快照**：由本轮所有已激活内部 end 的可见快照按 join 规则合并（被剪枝路径不参与）；同一轮多路径写同名变量按写冲突规则保存时禁止。

### 4. 状态、持久化与可靠性

沿用 Loop「写顺序不变量、resume 恰好推进一次、跳过去重、回填仅用于展示」理念，主键改用实例键。

- **Progress**：按实例键记录状态（待定 / 运行中 / 成功 / 失败 / 跳过 / 中断）。业务结点与循环容器计入分母；start / end、循环内部 end 不计入。被剪枝记跳过、失败记失败，二者均计入分子；硬停止取消的运行中实例记中断，不计入分子，续跑可重调度。
- **分母回算**：以运行时实例状态为唯一口径（不取「全部可能路径之和」，否则分支只走一条、循环提前结束永远到不了 100%）。
  - 启动给静态合法上界：主图按可达业务结点去重计数（diamond 汇聚只计一次）；If-Else 只按条件可达一侧计入（静态判不出则取互斥独占侧较大者，汇聚公共结点单独计一次）；循环按「容器 1 + 子图业务结点数 × 最大次数」，0 次只计容器自身。
  - 运行中每当边解析或循环轮次结束按实例状态动态修正：剪枝且未来不执行的实例从分母扣除；直到条件早停扣除剩余轮次；多 start / 多 end / 共享下游按实例键去重；复杂 DAG 不做更激进静态优化，只靠运行时剪枝与去重修正。
  - 失败 / 停止保留当时分子分母不强行回算 100%，续跑沿用已持久化分母继续修正；自然完成保证分子=分母。
- **运行配置快照**：GraphRun 启动时持久化一份不可变 graph 快照（nodes / edges / 初始变量 / disabledVars / 运行配置〔并发度、结点级与 job 级超时、循环最大次数兜底〕/ 会话策略）。后续编辑 workflow 只影响新 run，不影响已启动 run 的调度、续跑、崩溃恢复与历史查看；删除 workflow 不删既有 run 快照与记录，除非用户显式删除运行记录。
- **Resume / 续跑**：持久化已完成实例集合、实例状态、边三态、剪枝结果、循环当前/已完成轮次、实例可见快照、已写输出变量、各血缘会话、当前分子分母；续跑据此重推就绪队列，只调度未达终态且入边已解析的实例。
- **崩溃恢复**：重启从盘上状态重建就绪队列，未落终态的运行中实例按中断处理并允许重跑，终态实例不重复执行。
- **停止**：硬停止取消上下文、运行中实例标记中断；优雅停止不再调度新结点、等在飞实例结束、未调度实例保持待定；均保留状态以续跑。
- **在飞 Agent 取消**（含失败传播 / 超时取消）：内置（eino）Agent 直接取消上下文；ACP Agent 仅发 cancel / 中断当前 turn，**绝不 reset / 销毁 session**（项目约定：reset 会丢全部上下文），中断后实例标记中断、子进程归还进程池，续跑时在保留会话血缘上重跑。

### 5. 持久化与接口分层

严格按现有分层，handler 不直接读写文件：

- **`types/model`**：GraphWorkflow、GraphNode、GraphEdge、GraphNodeConfig、GraphRun、GraphRunSnapshot、GraphInstanceState、GraphProgress、GraphResumeState、GraphValidationError、Graph API Request/Response。
- **`types/path`**：graph workflow 配置 / 运行记录 / 实例状态 / 事件日志 / 迁移输出文件的路径拼接。
- **`repository`**：graph workflow CRUD、运行记录与不可变 run 快照读写，实例状态 / 边状态 / 变量快照 / 会话血缘 / progress 原子持久化，事件追加，迁移结果保存。
- **`services/graph`**：图合法性校验、条件表达式解析求值、变量快照合并、调度执行、循环驱动、resume / recover、停止控制、迁移编排。
- **`cmd/web/handler`**：参数解析、鉴权后服务调用、错误全量返回、响应格式化；路由统一注册在 `cmd/web/api.go`。

### 6. 前端与响应式（手机端）

独立 React Flow 画布入口，桌面 / 窄屏双适配：

- **画布**：触摸手势（单指平移、双指缩放），保留缩放 / 适配按钮，窄屏隐藏小地图等次要控件。
- **结点编辑 / 变量表**：桌面侧边 inspector，手机端改底部抽屉 / 全屏面板，单列布局、可点击区满足触摸尺寸。
- **添加结点**：手机端无原生拖拽，改「点选结点类型 → 画布点击放置」，连线用点选起点 / 终点辅助。
- **运行查看**：结点状态高亮、运行日志窄屏单列纵向滚动。
- 采用响应式断点（与现有前端约定一致），不依赖鼠标 hover。

## 风险

- **并发竞态**：变量单写者串行落库，progress 按实例键独立更新。
- **剪枝遗漏致 join 永久等待**：边三态机 + 全入边剪枝则自身剪枝，单测覆盖 diamond / 嵌套分支。
- **循环+并行嵌套致实例键膨胀**：实例键设计覆盖嵌套场景并加单测保证唯一可恢复。
- **Agent 会话 fork / cancel 行为不一致**：会话血缘持久化复制内容，ACP 不 reset session；fork / replay / cancel 失败均完整报错，并以续跑用例覆盖。
- **重复副作用**：贯穿瞬态重试、失败/超时取消后续跑、崩溃恢复重跑三场景。不变量是「已落终态（成功）不重跑、未落终态的运行中实例按中断可能重跑」，故 Shell 等带副作用结点在「执行完但状态未落库即被取消/崩溃」时可能重复一次；Shell 完整展示次数与 stdout/stderr/exit code，UI 提示带副作用命令需自行保证幂等。
- **模型输出协议不稳定**：Prompt / 评估用统一 marker 协议，缺失 / 重复 / 未声明 / 类型解析失败均失败并展示原始输出。

## 可观测性

- 统一用 `pkg/logger`，关键点打点：结点就绪 / 开始 / 完成（成功失败）、边激活与剪枝、循环每轮开始与终止判定、join 等待与触发、会话新建与继承、变量写入、并发入队出队、结点 / job 超时触发；失败全量输出错误信息。
- SSE 按实例键上报结点状态变化，前端画布据此高亮运行中 / 完成 / 失败结点。

## 执行步骤

0. **会话 fork / replay 可行性验证**（未执行）：动工前用 spike 验证「复制上游上下文新建独立 session」与「ACP replay 出等价 session」在现有 eino / ACP 链路可行（全方案最高风险假设），产出结论或替代方案；可与步骤 1~4 并行，但须早于步骤 9。
1. **图数据模型**（未执行）：在 `graph` 与 `types/model` 定义图结构（业务结点 / start / end / 边 / 配置）与实例键化 Progress/Resume。
2. **持久化分层**（未执行）：在 `types/path`、`repository`、`services/graph`、`cmd/web/handler` 落 graph 路径、存储、业务编排、HTTP 响应，handler 不直接读写文件。
3. **图合法性校验**（未执行）：按 §1 规则全量校验（start/end 边界与数量、控制结点无业务配置、不可达结点、普通结点入/出边、非法环、If-Else 端口、循环子图边界、条件表达式语法与括号配对、变量写冲突、多入边 Agent 禁继承会话），错误全量返回。
4. **调度器骨架**（未执行）：就绪队列 + 入边计数 + 拓扑串行执行（先不并发），跑通线性图。
5. **条件表达式与剪枝传播**（未执行）：统一条件求值（按声明类型比较、算子优先级与括号、字面量写法、未知/被剪枝变量报错、被禁用变量按空串）、`QUARTET_OUTPUT` 行首锚定解析带类型变量、边三态机与全入边剪枝则自身剪枝，覆盖 diamond / 嵌套分支。
6. **并发执行、超时与瞬态重试**（未执行）：全局并发调度（默认 4、最大 16、可配、1 退化串行，单一全局信号量含循环子图），结果串行落库；结点级与 job 级超时兜底（超时按失败处理并触发失败传播）；瞬态错误按 Loop 策略重试后再判失败。
7. **汇总（join）**（未执行）：等全部入边解析，至少一条激活则执行、全剪枝则跳过并传播剪枝；合并已激活上游快照。
8. **循环子图驱动**（未执行）：固定次数 / 直到条件 + 最大次数兜底；实例键含轮次上下文（覆盖嵌套）；每轮入口继承上一轮累积快照、轮末按激活内部 end 合并生成下一轮快照；覆盖 0 次、轮后判断、内部 end、全部剪枝结束本轮、失败传播、剪枝 progress、嵌套循环。
9. **会话血缘**（未执行）：沿边传递、并行分叉复制上游上下文后新建独立会话、多入边 Agent 强制新建；会话策略来自结点配置（不依赖 roundMode），保证每条 start 链路首个可执行 Agent 新建会话；取消在飞 ACP Agent 只发 cancel 不 reset session。
10. **变量产出**（未执行）：可执行结点声明带类型输出变量，按统一协议解析（失败即结点失败）；单写者串行落库；按实例维护可见快照、执行时取快照替换；保存时禁止同一可并行区域写同名变量。
11. **状态与可靠性**（未执行）：实例键化 progress/resume/recover，持久化实例状态、边三态、变量快照、会话血缘、循环上下文；落实分子分母规则、剪枝与早停回算、停止 / 优雅停止、失败传播。
12. **接入入口**（未执行）：graph 工作流创建 / 编辑 / 保存 / 删除 / 列表，运行记录创建与不可变快照保存，运行 / 硬停止 / 优雅停止 / 续跑 / 查看运行状态 / 查看历史记录（路由、handler、前端页面），与 Loop 并列。
13. **事件流与前端**（未执行）：SSE 按实例键上报；新增独立 React Flow 画布入口，桌面 + 手机端双适配（触摸手势、抽屉式编辑、点选放置 / 连线）。
14. **迁移脚本**（未执行）：graph 页面提供单个旧 Loop 配置手动迁移入口，结果保存为新 graph workflow 进列表、不回写原配置；重复迁移新建副本不覆盖；失败不写半成品并完整报错。转换覆盖 roundMode（按 §3 映射表）、group iteration、评估 STOP、variables/disabledVars、Shell/Prompt 配置、空 prompt step 与异常旧配置错误返回。
