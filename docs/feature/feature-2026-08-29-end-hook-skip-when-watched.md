# 技术方案：对话结束 Hook 只在无人实时查看时通知

## 背景

`feature-2026-08-28-task-end-hook.md` 把全局默认 Hook 扩成「任务结束通用 Hook」，对话每一轮结束（完成 / 失败 / 停止）都会执行设置页那段脚本。该文档的风险一节已经预告了随之而来的问题：**对话每轮都通知会很吵**，并留了「如后续仍嫌吵，再考虑增加开关」。

最吵的一种情况是用户本来就在盯着这轮的流式输出：任务跑完的那一刻他已经看到了，通知纯属噪音。本方案给对话侧的结束 Hook 加上「有人在看就不通知」的判定。

## 目标

对话轮次结束时，若该任务正在被人实时查看，就跳过 Hook；页面关掉、切到别的任务、退到后台或标签页不可见之后，才把通知发出去。图工作流终点 / Prompt 结点 Hook 的行为不变。

## 范围

**做**：

- 服务端记录「谁在实时看哪个任务」，并在对话轮次结束触发 Hook 前做判定。
- 判定要区分「连接还在」和「人真的在看」：浏览器隐藏标签页会保持事件流连接，前端按可见性变化上报。
- 设置页（Web + iOS）加一个开关，默认开启，可关掉恢复「每轮都通知」。
- 给 Hook 脚本注入「本轮结束时是否有人在看」的环境变量，开关关掉后脚本也能自己判断。

**不做**：

- 不改图工作流终点结点的三态配置，也不给图工作流终点 Hook 加同类判定。
- 不做「等一会儿再看有没有人来看」之类的延迟通知，判定只发生在触发那一刻。
- Hook 仍是纯副作用：跳过与执行都不影响任务状态，失败只打日志。
- 不为跳过事件增加前端展示位，只写一条服务端日志。

## 判定口径

「有人在实时看任务 X」= 该任务上至少有一条**可见的**用户界面事件流连接。

- **算**：Web 对话页（标签页可见）、iOS 对话页（应用在前台）、任务的图运行页——图任务里结点对话轮次结束时，用户确实在看这个任务。
- **不算**：公共分享页的读者（通知是发给任务归属者的，不是发给拿到链接的人）、IM 网关这类服务端内部订阅者、浏览器隐藏标签页 / 最小化窗口、iOS 退到后台。

判定依据是现成的：Web 与 iOS 打开对话页时都会挂一条该任务的事件流，切走、关页面、iOS 退后台都会主动断开；轮次终态事件不会让客户端断流，所以 Hook 触发那一刻，正在看的连接一定还在。

## 用户流程

1. 设置页填好结束 Hook 脚本，保持「仅在无人实时查看该任务时执行」勾选（默认）。
2. 在对话页发消息并一直看着：Agent 回复结束，不发通知。
3. 关掉页面（或切到别的任务、锁屏、切到别的浏览器标签），下一轮结束时通知照常发出。
4. 想恢复「每轮都通知」就取消勾选；想做更细的判断（例如失败才通知、有人看时改发静默渠道）就在脚本里读那个环境变量自行分支。

## 方案设计

### 1. 观看者记录

- 服务端在**鉴权后的**事件流接口上登记观看者，连接结束即注销。走内部订阅的消费者（IM 网关）与公共分享流不登记，天然被排除。
- 每条连接携带一个前端生成的连接标识和初始可见性；标识缺省时（iOS、命令行客户端）按「始终可见」处理，因为这些客户端不看时会直接断流。
- 记录只存在于进程内存：重启后所有连接本来就断了，无需持久化。

### 2. 可见性上报

- Web 端在标签页可见性变化、页面被冻结 / 离开时上报当前可见性；重连成功后重报一次，避免重连按旧的可见性重新登记。
- 上报是「即发即忘」：失败只写浏览器控制台，最坏结果是多发或少发一次通知，绝不打扰用户。
- iOS 不需要上报：离开页面与退到后台都会断流。

### 3. 配置与判定

- 全局设置新增开关，缺省视为开启——升级前的配置不需要改动就获得安静行为；想每轮都通知的人显式关掉。
- 对话轮次结束触发 Hook 前读取开关与当前观看者数量：开关开启且有人在看就跳过，并记一条 info 日志（含任务标识、观看者数量、本轮结果）。「怎么不通知了」只看这一行日志即可定位。
- 无论跳过与否，脚本都能读到一个表示「本轮结束时是否有人在看」的环境变量（沿用 `QUARTET_` 保留命名空间，最后注入，用户变量无法覆盖）。

## 已知边界

- **关页面的同一瞬间任务结束**：服务端感知连接断开有延迟（正常几十毫秒，网络异常时最长到事件流写超时），极少数情况会判成「有人在看」而漏发一次通知。
- **合盖 / 断网**：标签页仍是可见状态，但连接会断，之后按「无人查看」通知。
- **多标签页看同一个任务**：任一可见即算有人在看。
- **忘记关的可见页面**：确实会一直安静，这正是开关存在的意义。

## 验收标准

- Web 对话页开着并可见时发消息，轮次结束不执行脚本，服务端有一条跳过日志。【手工】
- 关掉页面或切到别的任务后再触发同一任务（命令行 / 定时任务 / IM），脚本执行，环境变量显示「无人查看」。【手工】
- 对话页开着但切到别的浏览器标签，轮次结束照常执行脚本。【手工】
- 图运行页开着时，结点对话轮次结束不执行脚本。【手工】
- iOS 前台看着不执行；退后台或锁屏后执行。【手工】
- 公共分享链接打开着，轮次结束仍执行脚本。【手工】
- 设置页（Web / iOS）取消勾选后恢复每轮都执行，且脚本里的「是否有人在看」取值正确；开关状态可持久化，其它设置项不被覆盖。【手工】
- 图工作流终点 Hook 行为不回归。【手工 + 既有用例】
- 后端 `make build-all`、前端 `npm run build` 通过，既有 graph / job 用例（含 race）不回归。
