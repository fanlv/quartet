# 消息时间戳展示

## 目标

给所有用户发送的消息和模型回复的消息加上发送时间，前端可见。

## 实现概述

### 后端

- 交互模式（非 Shell）：handler 收到请求时即在用户消息的 Extra map 中写入 `KeyStartedAt`，确保持久化后历史查询可还原发送时间
- Shell 模式：沿用已有逻辑，`KeyStartedAt` 取自进程启动时间（与用户发送时间差异极小）
- 模型回复：已有正确的 `KeyStartedAt` 和 `KeyFinishedAt`，无需改动
- 历史查询接口已正确提取 Extra 中的时间戳并返回给前端

### 前端

- 历史消息转换时，用户消息的 `createdAt` 改为从后端返回的 `startedAt` 取值，不再使用页面加载时间
- 用户气泡和助手气泡底部右下角展示格式化后的时间
- 助手消息在流式输出过程中不展示时间，完成后才显示
- 新增 `formatMessageTime` 工具函数统一格式化

### 时间格式规则

- 当天：`HH:mm`（如 `14:32`）
- 非当天同年：`MM-DD HH:mm`（如 `05-18 14:32`）
- 跨年：`YYYY-MM-DD HH:mm`
- 时间戳为 0 或缺失时不展示

### 展示样式

- 字号 11px，低透明度次要色
- 用户气泡用白色半透明，助手气泡用灰色
- 位置在气泡内容下方靠右
