Quartet 项目系统架构

本地优先的 Agent 工作台 · React 前端 + Hertz Web 后端 + 文件型持久化 + Agent / Graph 运行时

架构图 (Architecture Diagram) — 展示当前项目的顶层组件、调用关系、数据流与外部依赖。

交互入口

  • React SPA 通过 `/api/v1/*` 访问本地 Hertz 后端。
  • 健康检查免鉴权，业务接口走 agent token 或 share token。
  • Job 和 Graph Run 使用 SSE 将运行事件推回前端。

核心运行域

  • Job Service 负责普通会话、循环任务和消息续跑。
  • Graph Service 负责工作流配置、DAG 调度、版本更新和恢复。
  • Schedule Service 通过 cron 触发图工作流运行。

Agent 执行

  • Eino Runner 承载内置 Quartet Agent。
  • ACP Runtime 管理外部 Agent 子进程和会话缓存。
  • Round Middlewares 统一处理 AGENTS.md、工具包装、上下文归约和沙箱。

持久化与集成

  • repository 层以 `types/path` 生成的路径读写 LOCAL_MEMORY。
  • 本地文件保存 workspace、job、session、settings、schedule 和 graph run 产物。
  • 模型提供商、IM 平台、本地 shell 与 sandbox 是主要外部依赖。
