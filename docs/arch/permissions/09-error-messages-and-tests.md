# 09 · 鉴权错误与测试

## 错误语义

| HTTP 状态 | 含义 |
| --- | --- |
| 400 | 登录、初始化或管理请求参数不合法；返回完整校验错误 |
| 401 | Cookie 不存在、无效或已过期 |
| 403 | 已登录，但缺少路由所需权限；或 CSRF 校验失败 |
| 409 | 初始化已完成，或用户/角色版本冲突 |
| 429 | 同一用户名与来源的连续登录失败触发短时限流 |
| 503 | 系统尚未初始化，或认证配置处于恢复态 |

错误响应必须包含可直接展示的完整原因，但不得包含密码、Cookie、会话摘要或 CSRF 凭证。即使启用 HTTP body 日志，认证请求与响应正文也必须脱敏。

## 测试边界

- 首次初始化、错误初始化码、重复初始化和恢复态。
- 正确及错误密码、登录限流、Cookie 刷新后复用和退出失效。
- 修改请求缺少或携带错误 CSRF 时返回 403。
- `admin`、`member`、`viewer` 与自定义角色的路由权限矩阵。
- 用户停用、删除、重置密码后已有会话失效。
- 旧共享请求头和私有 URL token 不能授权请求。
- 普通请求、文件、图片和 SSE 均通过 Cookie 访问。
- 公开 Job/file 分享仍只使用 shareToken/fileShareToken。

浏览器 E2E 使用隔离的 `LOCAL_MEMORY`，启动后通过真实初始化接口创建测试管理员，并让浏览器与 API fixture 携带测试 Cookie/CSRF。
